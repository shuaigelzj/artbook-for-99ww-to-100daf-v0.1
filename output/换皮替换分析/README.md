## 标记含义

“可直接”指已有完整、可辨认的设计单元，可以用现有图示或该单体的新视角制作主效果图。它不表示模型可以跳过骨骼、握持、门轴、碰撞和脚本接口检查直接接入工程。

| 标记 | 数量 | 判定与处理 |
| --- | ---: | --- |
| 是 | 607 | 完整建筑、角色、生物、武器、物品、头饰等；可先出完整单体主图，配套姿态/状态按条目方案补充 |
| 否 | 222 | 先完成铺排、组装、试穿、界面版式、效果时序或场景分镜，再制作效果图 |
| 待确认 | 46 | 宿主、用途或默认显示状态不足以确认；每条均给出追查入口与条件式组合方案 |
| 不适用 | 30 | 当前是空容器、逻辑/定位结构或开发占地样板；保留它，设计其实际可见宿主或补齐缺失内容 |

“用途待确认”与“能否单体出图”独立。例如完整木箱即使正式用途未核实，仍能出外观图；透明 RootPart 即使已确定被使用，也没有独立美术造型可换。标记不用于判定无用或删除资产。

## 配套关系的证据边界

配套编号默认表示**建议演示载体或同题材对照**，不表示已经证明原工程存在装配引用。逐条记录会说明“配置同系列”“同目录参考”“代码确认某类载体”等具体范围。角色试穿示例还需匹配实际 Rig 类型和身体比例。

“部件合并”在制图阶段指把副本按原局部坐标放入临时 Model、形成完整装配单元。保留各部件、挂点和控制节点；生成整体风格后再拆回原部件，并不要求把网格做成一个 Union。

## 典型准备方式

| 类型 / 示例 | 先准备的制图单元 | 效果图与回拆方案 |
| --- | --- | --- |
| 地块 AF-0027～0048、AF-0760、AF-0818 | 按当前 50-stud 小格建立 5×5 局部样区，约250×250 studs；事件、池塘地块在中心放一份并配相邻地面 | 俯视＋45°＋边缘接缝/高差；按原合法旋转测试，再拆回顶面、侧面、覆盖层与装饰。透明/留空地块保留原可见性 |
| 积雪、地表片、草簇 | 原地块或宿主＋覆盖层/植被，保留局部坐标与密度 | 看完整宿主与边缘穿插，再拆回覆盖网格、贴片和材料 |
| 枪托 AF-0186、枪身 AF-0200、枪管 AF-0276 | 对照完整步枪 AF-0242 还原整枪装配 | 整体、侧视与标出本件范围的拆分图；生成新整枪风格后回拆，保留 Handle/Grip 与接口 |
| 墙、门、梯、铁路、车甲 | 连续直段＋转角/门洞，或上下层平台/原车厢 | 拍完整连接组件与接缝，再回拆每段；保留连接尺寸、门轴、轨距和通行空间 |
| 冰刺 AF-0353～0355、护甲/围巾/眼睛 | 匹配的完整 Rig；马鞍 AF-0762 则配原坐骑和骑手 | 正侧背与活动姿态，明确左右件和遮挡；回拆配件并保留 Attachment/关节变换 |
| UI、血条、冷却、说明卡模板 | 固定比例画板＋真实长度示例数据＋实际宿主 | 实际状态板与小尺寸可读性对照；回拆背景、图标、字体和伸缩条，保留控件名与数据绑定 |
| Effects AF-0598、WetModel AF-0648、Beam 载体 | 子效果分别挂到实体；光束给两端，拖尾给运动路径，Highlight 给实际载体 | 原生场景/运行态的启动、峰值、消散套图；保留生命周期、端点与触发时序。静态视窗只作结构参考 |
| CamSetting AF-0899、老矿镇 AF-0414、车厢战场 AF-0510、洞穴 | 整体总览＋按子场景/镜头拆分的玩家视高套图 | 先统一主题再分组替换，保留道路、门洞、刷怪/奖励点、镜头点及原层级 |

5×5 是建议制图样区，不是完整运行地图大小。50-stud 网格来自当前 DefaultSetting；地块四向90°、建筑正方形四向与长方形轴向规则来自 MapService/MapHelper 的生成代码快照。方案需要运行状态时应在隔离演示场景验证，不能只依赖本轮静态截图。
