## 如何填，填到什么程度

1. 表格中的 **【待填】** 替换成你的决定；“状态”改为 **已确认／暂缓／不替换**。带★是准备该组生图前的必填项。
2. 全局只填共同规则。每个单元填新版身份、造型/材料/局部色、细节/破败/变体；可以写“继承全局＋具体差异”。不要只填“废土风”，那不足以决定画面。
3. 新版方向例子在单元下方，仅供选择；没有写入回填表的例子，不会进入生图指令。
4. 同类不同变体共享一行；特殊实例填OV表。已确认设定采用“单资产覆盖＞单元＞全局”，并保留原工程硬约束。
5. 建议先回填 T01普通地面、B01代表木屋、D01/D02植被，确认一组样张方向，再扩展寒区、沼泽与大型聚落。其他行可以先暂缓。

可直接编辑这些Markdown文件。下一步读取你回填的文件后，先检查缺项和冲突，再按设定做图；对需要铺排/装配的对象，会按预填方式准备正确的原版输入。

## 这份清单的覆盖范围

共 **79个环境设计单元，对应273条不同原资产**，另有 **58条边界资产**单列。原目录中“地形植被89条＋建筑场景157条”的 **246条全部有归属**；还补入上一轮图示复核识别出的家具、旗、墙板、草簇等相关样本。设计族共享不等于几何相同、正式已用或互相可替换。

树木砍伐、矿脉、容器、营地制造等玩法对象不冒充非交互装饰；建筑等含功能物件只设计可见环境壳。散放样本的“用途待确认”原结论没有被本册覆盖。未落实宿主的无名块体也没有强行归为地形。
